### Coverage equation

The denominator is the exact output of `git ls-files` at the application/final source checkpoint. The new audit files are untracked outputs and do not change it.

### Reproducible precedence rules

Every tracked path receives exactly one disposition in this order:

1. **Excluded with reason (76):** path matches one of the exact exclusion groups below.
2. **Deeply inspected (383):** a non-excluded path either appears literally (forward- or backslash form) in the UTF-8 concatenation of all 22 audit reports, or matches one of these exact mandatory classes: `\.md$`; `^src/app/api/(?:.+/)?route\.(?:ts|js)$`; `^src/app/(?:.+/)?page\.tsx$`; exact `db/schema.ts`; or `^drizzle/\d{4}_.+\.sql$`. Literal mentions account for the specifically reviewed runtime, config, test, provider, component and library files. “Deep” includes structured semantic parsing plus targeted line review; it does not claim every byte was manually read.
3. **Mechanically scanned (216):** all remaining non-excluded tracked paths. These received extension/path/size/search-family/import/reference classification and were included in dependency/route/component/test discovery, but did not receive a material claim requiring targeted line analysis.
4. **Inaccessible (0):** no tracked path was unreadable. Production/provider systems are external gaps, not tracked-file gaps.

The exclusion predicate is exactly: binary extension in `.png/.jpg/.ico/.xlsx`; either lockfile; `^drizzle/meta/\d{4}_snapshot\.json$`; `^fixtures/synthetic/migrations/`; or exact `public/electricity-comparator.html`. Apply it before the deep predicate; every remaining path is mechanical. The equivalent count operation is:

```powershell
$corpus = ((Get-ChildItem $audit -File -Filter '*.md' | ForEach-Object {
  Get-Content $_.FullName -Raw -Encoding UTF8
}) -join "`n")

foreach ($path in (git -C $repo ls-files)) {
  # Apply the exact exclusion predicate above first.
  $mandatory = ($path -match '\.md$') -or
    ($path -match '^src/app/api/(?:.+/)?route\.(?:ts|js)$') -or
    ($path -match '^src/app/(?:.+/)?page\.tsx$') -or
    ($path -eq 'db/schema.ts') -or
    ($path -match '^drizzle/\d{4}_.+\.sql$')
  $mentioned = $corpus.Contains($path) -or $corpus.Contains($path.Replace('/', '\'))
  # mandatory OR mentioned => deep; otherwise => mechanical.
}
```

This exact rule reproduces 383 deep, 216 mechanical and 76 excluded at final checkpoint after the final report expansions. `20_EVIDENCE_INDEX_AND_COMMAND_LOG.md` records the broader inventory method and top-level counts.
